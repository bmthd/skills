# Fork to Worktree

この会話そのものを新しい worktree に移す。同じセッションを、これまでのやりとりをすべて持ったまま、そこで resume する。ユーザーは移った先で同じ文脈と話し続け、こちらの会話は止まる。

## 手順

1. **worktree を作る**。ターミナルマルチプレクサで、最新の既定ブランチから作り、作業の対象の Issue や PR にひも付ける。作業に要るコミット前の変更があれば一緒に持っていく。
2. **このセッションをそこで resume する**。worktree でマルチプレクサの新しいペインを開き、同じエージェントとモデルで、このセッションを ID で resume する。エージェントにできるなら新しいセッション ID に fork し、2 つの会話が同じ記録に書き込まないようにする。
3. **次の一歩を渡す**。最初のメッセージとして、ユーザーの引数を渡す。なければ、自分が次にやろうとしていたことを渡す。
4. **確かめる**。resume した会話がこの会話を覚えていて、次の一歩に取りかかったことを確かめる。worktree のパス、ブランチ、ペインを報告し、こちらではその作業をやめる。
