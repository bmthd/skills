# Move to Worktree

この会話の作業を新しい worktree に移し、新しいエージェントに続けさせる。エージェントが動き出したら、ユーザーはそちらと話し、あなたは手を止める。

## 手順

1. **worktree を作る**。ターミナルマルチプレクサで、最新の既定ブランチから作り、作業の対象の Issue や PR にひも付ける。
2. **エージェントを起動する**。ユーザーが別のものを指定しない限り、自分と同じエージェントとモデルにする。
3. **引き継ぎの指示を渡す**。最初のプロンプトとして渡す。エージェントは何も知らずに始まるので、指示には次を入れる。
   - 作業の内容。Issue や PR があればそれを示し、そこに書いてあることは繰り返さない
   - この会話でユーザーが決めたことと、まだ決まっていないこと
   - 調べて分かったこと（ファイル、関数、制約）
   - ハーネスが会話の記録を残していれば、そのパス
   - どこから始めるか。ユーザーの引数、なければ次の一歩
   - ユーザーが付けた条件（どこで止まって確かめてもらうかなど）と、返答に使う言語
4. **確かめる**。プロンプトが届き、エージェントが動いていることを確かめる。worktree のパス、ブランチ、エージェントの居場所を報告する。
